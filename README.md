# محتوى مكتبة عبد الحسيب منيب (الخادم المركزي)

حقوق الطبع والنشر محفوظة للمؤلف عبد الحسيب منيب.

الكتب والتسجيلات في هذا المستودع **مشفّرة**، ولا تُفتح إلا داخل تطبيق «المكتبة العلمية». ولا يجوز بيعها ولا نشرها ولا نسخها إلا بإذن مكتوب من المؤلف.

## طريقة العمل

يقرأ التطبيق ملف `manifest.json` كلما فُتح وكان الإنترنت متصلًا، فينزّل ما جدّ أو تغيّر، ويعمل بعد ذلك بلا إنترنت.

| المفتاح في manifest.json | معناه |
|---|---|
| `books` | الكتب الجديدة أو المعدّلة. تُجهَّز بأداة الحزم مشفّرةً في مجلد `books`. |
| `hide` | أرقام كتب تُخفى من المكتبة عند المستخدمين، مثل `["mt_arqam"]`. وتعود إذا حُذف رقمها من القائمة. |
| `remove` | أرقام كتب نزلت من الخادم وتُحذف من أجهزة المستخدمين. |
| `audio` | التسجيلات الصوتية لكل كتاب، في مجلد `audio`. |
| `notice` | إعلان يظهر مرة واحدة لكل مستخدم. يُكتب هكذا: `{"id": "n1", "text": "نص الإعلان"}`، ويُغيَّر `id` لكل إعلان جديد. |

- **ما تفعله بيدك:** الإخفاء والإعلان. عدّل الملف، ثم احفظه، ثم ارفعه بـGitHub Desktop.
- **ما يُجهَّز بأداة الحزم:** إضافة كتاب أو تسجيل، لأنها تحتاج إلى التشفير.
